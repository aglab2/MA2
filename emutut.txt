!!! Make sure you are using latest versions of emulators. Luna PJ64 3.5.5, RMG v0.7.2, Parallel Launcher 2.21.2 or lower will not work. !!!

This romhack uses F3DEX3 features and requires modern emulator supporting it.

Supported platforms:
N64 Console + SummerCart/EverDrive X7
  Culling features are used to ensure high performance which can lead to occasional flickering. Sorry for inconvenience.

Parallel Launcher with Parallel core v2.21.2 or higher + OGRE

Luna Project64 v3.5.6 or higher with ANGLE GLideN64 4.3.16
  Options > Configuration > Plugins > Video plugin > ANGLE GLideN64
  No FB emulation (Options > Graphics Settings > Frame buffer > uncheck Emulate frame buffer) 
  Enable Noise (Options > Graphics Settings > Emulation > check Enable Noise)

RMG v0.7.3 or higher with GLideN64
  Settings > Settings > Plugins > Video Plugin > GLideN64
  FB emulation (Settings > Graphics > Frame buffer > check Emulate frame buffer)

Android: Luna Mupen64PlusAE https://github.com/aglab2/mupen64plus-ae/releases/tag/1.3
  Support is limited. I am not great at mobile development to guarantee it works on every phone but it worked on mine.
